# Clairvoyance Icon Sets

Icon sets for [Clairvoyance](https://www.clairvoyanceai.com), chosen in **Settings → Appearance → Icon Set**.

## Install

Copy a `.json` file into `config/icon-themes/` in your Clairvoyance data folder (Windows: `%APPDATA%\clairvoyance\config\icon-themes\`), then restart Clairvoyance. Give your own variations a new file name, because files that ship with the app are refreshed on launch.

## Contents

| File | Name | Description |
| --- | --- | --- |
| `colored-paper.json` | Colored Paper | Solid, muted paper sheets and folders with a lighter folded corner and white glyphs. Separate 16px drawings keep tree rows crisp. |
| `fluent.json` | Fluent | Soft, straight-on Windows 11 style: white sheets with a colored type plate, amber folders with paper inside, and gentle top-lit gradients.… |
| `monoline.json` | Monoline | Linework glyphs in a single quiet tone, with accent-colored folders. |
| `porcelain.json` | Porcelain | Glossy white sheets with a colored type badge, and soft cornflower folders with a light top edge and gentle shadow. |

Use any item here as a starting point. To list yours in the app's community catalog, put it in your own GitHub repository and open a pull request on [clairvoyance-releases](https://github.com/clairvoyanceapp/clairvoyance-releases).
